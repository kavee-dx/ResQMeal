\# ResQMeal



\## Community Food-Sharing \& Surplus Mobile Application



ResQMeal is a mobile application that connects food donors with recipients through real-time donor-recipient matching and a volunteer delivery network.



\## SDG Alignment



\- SDG 2 - Zero Hunger

\- SDG 12 - Responsible Consumption and Production



\## Technology Stack



\### Frontend

\- React Native

\- Expo

\- NativeWind (Tailwind CSS)

\- React Navigation

\- Zustand



\### Backend

\- Node.js

\- Express.js

\- MongoDB Atlas

\- Mongoose



\### Services

\- JWT Authentication

\- bcrypt Password Hashing

\- Cloudinary Image Storage

\- Google Maps API

\- Socket.IO

\- Expo Notifications



\## Main Features



\- Food Donation Management

\- AI Food Donation Priority System

\- Smart Expiry Alerts

\- Digital Food Rescue Map

\- Hotel/Restaurant Integration

\- Emergency Food Requests

\- Volunteer Delivery Network

\- Real-time Donor-Recipient Matching
